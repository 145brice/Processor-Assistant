# Official lender resources

`catalog.json` is the canonical source for lender links shown beside scanned
approval files in Processor Assistant. Keep links limited to official lender
domains and public documents. Never add borrower-specific portal URLs, signed
URLs, credentials, loan numbers, or other customer information.

The application matches a detected lender name against the catalog aliases and
shows the corresponding resources in that file's scan result. It does not send
file or borrower information when creating the links.
